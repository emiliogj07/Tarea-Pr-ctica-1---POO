# Tarea-Pr-ctica-1---POO

Programación Orientada a Objetos con Java

Proyecto realizado para practicar los conceptos básicos de programación orientada a objetos.

Ejercicios

1. Sistema de Biblioteca

Permite registrar libros y usuarios, prestar libros, devolverlos y consultar su disponibilidad.

Clases: Libro, Usuario, Prestamo y MainBiblioteca.

2. Sistema de Vehículos

Permite crear vehículos utilizando diferentes constructores y calcular costos estimados de mantenimiento mediante sobrecarga de métodos.

Clases: Vehiculo y MainVehiculos.

3. Empresa de Telefonía

Permite registrar clientes y planes telefónicos, calcular cargos por consumo adicional y generar facturas.

Clases: Cliente, Plan, Factura y MainTelefonia.

Conceptos utilizados

Clases y objetos.

Atributos privados y métodos públicos.

Constructores.

Sobrecarga de constructores y métodos.

Relaciones entre objetos.

Herramientas

Java

Apache NetBeans

Apache Ant

Ejecución

Abrir el proyecto en NetBeans.

Seleccionar el archivo Main del ejercicio.

Hacer clic derecho y elegir Run File.

Asignatura: Programación 1 – ITLA
